# Netflix Homepage UI Clone

A responsive Netflix Homepage UI clone built using HTML, CSS, and JavaScript as part of a UI Clone Challenge. This project focuses on frontend UI design, layout accuracy, responsiveness, and user experience, with no backend or authentication included.

## 📌 Project Overview

The primary objective of this project is to recreate the Netflix Homepage interface as closely as possible using core web technologies. It includes multiple content rows, a featured hero section, and a Netflix-style "Top 10 in India Today" ranking section.

This project demonstrates:
- Proficiency in layout design and UI replication.
- Expertise in responsive web development.
- Attention to detail in real-world UI elements.

## 🛠️ Technologies Used

- **HTML5**: Semantic markup for page structure and layout.
- **CSS3**: Advanced styling, animations, and responsive design.
- **JavaScript (Vanilla JS)**: Interactive UI elements and basic functionality.
- **Font Awesome**: Icon library for enhanced visual elements.
- **TMDB Image CDN**: Source for movie and show posters.

## ✨ Features

- **Hero Banner**: Netflix-style banner with gradient fade effects.
- **Content Rows**: Multiple horizontal scrolling rows including:
  - New This Week
  - Trending Now
  - Only on Netflix
  - Action & Thriller
  - K-Dramas
  - Anime
- **Top 10 Section**: "Top 10 in India Today" with large background numbers.
- **Responsive Design**: Optimized for desktop, tablet, and mobile devices.
- **Interactive Elements**: Smooth hover effects and scaling animations.
- **Dark Theme**: Netflix-inspired dark color scheme.
- **Performance**: Lightweight and fast-loading without heavy frameworks.

## 📱 Responsive Design

The UI adapts seamlessly across devices using:
- CSS `clamp()` for fluid typography.
- Media queries for tablet and mobile breakpoints.
- Horizontal scrolling for content rows on smaller screens.
